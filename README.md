# ☕ Hema Brew Cafe - Task 2 Landing Page

Hema Brew Cafe is a modern and responsive coffee shop landing page developed using HTML and CSS.
 This project was designed completely with my own creativity, styling, and layout ideas. The website provides a clean and attractive user interface with coffee menu sections, an online order form, cafe details, and responsive design suitable for all devices.

## Features

- Attractive Hero Section
- About Cafe Section
- Popular Coffee Menu Cards
- Online Order Form
- Contact Section
- Responsive Design

## Technologies Used

- HTML5
- CSS3

## Project Objective

The objective of this project is to improve front-end web development skills by creating a visually appealing and responsive landing page using custom design and styling concepts.

##  Key Highlights

- Designed with my own styling ideas
- Clean and beginner-friendly code
- Responsive layout for mobile and desktop
- Interactive buttons and hover effects
- Creative cafe-themed design
